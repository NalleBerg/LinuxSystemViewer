v 0.17.0 — 2025-11-24

Major Redesign - Complete Tab System Overhaul

  • Architecture: Eliminated external helper dependencies (lshw, lscpu, lspci, etc.) — all system information now read directly from /sys and /proc filesystems for instant loading and zero external dependencies
  • UI Pattern: Introduced consistent CPU-inspired design pattern across all tabs with 2-column property/value tables, bold first column, word wrap, ResizeToContents, and arrow (↳) for multiline values
  • Performance: Instant tab loading (no more waiting for external commands to execute)

Redesigned Tabs

  • CPU Tab: New QWidget-based design with direct /proc/cpuinfo parsing, real-time frequency monitoring, temperature sensors, cache info; Geek mode shows all cpuinfo properties, CPU flags, and detailed cache hierarchy
  • Motherboard Tab: Complete rewrite reading from /sys/class/dmi/id/, displays board info, BIOS details, chassis type; Geek mode with all DMI properties and Copy/Save/Close buttons
  • Graphics Tab: Direct DRM subsystem access via /sys/class/drm/, GPU detection, frequency/power monitoring for all cards (not just card0); Geek mode with comprehensive GPU properties and DRM connector details
  • Screen Tab: Qt QScreen API integration + EDID parsing from /sys/class/drm/, shows resolution, refresh rate, zoom level, physical size, manufacturer (from EDID), orientation; Geek mode with all Qt screen properties, DRM connector info, and formatted EDID hex dump with proper word wrapping
  • PC Info Tab: DMI/SMBIOS information from /sys/class/dmi/id/, displays computer name, PC type (decoded from chassis), manufacturer, product, family, version, serial, SKU, UUID; Geek mode shows all DMI files, hostname, machine IDs, hostnamectl output, firmware type (UEFI vs Legacy BIOS with platform size), ACPI tables, boot cmdline, system uptime (formatted and raw)
  • Ports Tab: Direct /sys access for USB buses/devices, serial ports (ttyS*/ttyUSB*/ttyACM*), PCI USB controllers, Bluetooth adapters, network interfaces; Geek mode with comprehensive USB device properties, serial port details, PCI controller info, Bluetooth adapter info, network interface properties; Copy/Save/Close buttons with proper dialogs
  • Summary Tab: System overview aggregating key information from all subsystems — computer name, manufacturer, processor, CPU cores, total memory, system uptime (formatted as "X d, Y h, Z m"), storage devices, total storage, graphics cards, display resolution, refresh rate, number of screens, Ethernet/wireless interfaces, USB devices, OS, kernel version

UI/UX Improvements

  • Geek Mode Dialogs: Standardized 700x500px modal dialogs with Copy (confirmation dialog), Save (CSV export with proper escaping), and Close buttons; Auto-refresh timers with show/hide event handlers
  • Copy Functionality: Right-click context menu + Ctrl+C support across all tables, timer pause during copy operations, "Copied" confirmation dialogs
  • Multiline Display: Consistent use of ↳ arrow character for line breaks in table cells, word wrap enabled, ResizeToContents for property column
  • Serial Ports: Comma-separated list with natural line breaks (word wrap) instead of arrow between every item
  • Header Colors: Standard #2c3e50 (dark blue-gray) for normal mode, #34495e for geek mode

Technical Changes

  • Base Class Migration: Moved from TabWidgetBase to direct QWidget inheritance for 7 tabs (CPU, Motherboard, Graphics, Screen, PC Info, Ports, Summary)
  • GUI Helpers: Introduced createHeadlineWithGeek(), enableTableCopy(), applyMainLayoutDefaults(), styleGeekButton() for consistent styling
  • System Access: Direct filesystem reads from /sys/class/drm/, /sys/class/dmi/id/, /sys/bus/usb/devices/, /sys/class/tty/, /sys/bus/pci/devices/, /sys/class/bluetooth/, /sys/class/net/, /proc/cpuinfo, /proc/meminfo, /proc/uptime, /proc/version, /etc/os-release
  • Arrow Character: Standardized on ↳ (U+21B3, downwards arrow with tip rightwards) across Storage, Ports, and all tabs for multiline display consistency
  • Signal Connections: Removed TabWidgetBase::loadingStarted/loadingFinished connections for redesigned tabs in lsv.cpp

Internationalization

  • Norwegian Translation: Updated lsv_nb.ts with 311 finished translations (69% complete) including all new Ports and Summary tab strings
  • Translation Quality: Professional Norwegian (Bokmål) translations with proper technical terminology and UI conventions

Bug Fixes

  • GPU Frequency: Fixed Intel GPU frequency display by scanning all DRM cards instead of hardcoding card0
  • Uptime Calculation: Fixed to parse /proc/uptime as double instead of long long for accurate sub-second precision
  • Column Truncation: Fixed "USB Buses/..." truncation by using ResizeToContents for first column in all tables
  • EDID Display: Added spaces between hex bytes in EDID dump to enable proper word wrapping

Files Changed (Major)

  • motherboard_tab.h/cpp — complete rewrite, DMI access
  • graphics_tab.h/cpp — complete rewrite, DRM subsystem
  • screen_tab.h/cpp — complete rewrite, Qt + EDID parsing
  • screen.h — new helper file for screen information
  • pc_tab.h/cpp — complete rewrite, DMI/SMBIOS
  • ports_tab.h/cpp — complete rewrite, /sys access

Known Limitations

  • Some older tabs (Audio, Desktop, OS, Peripherals, Memory, Network, Windowing) still use TabWidgetBase pattern and external helpers — planned for redesign in v0.18.0
  • Remaining 141 untranslated strings (31%) in Norwegian translation — to be completed in next version
