v 0.7.2 — 2025-11-06

Changed

  • Packaging and elevation: prefer a terminal-based elevation flow when launched from the desktop/file-manager to avoid pkexec/polkit failures; added helper installer/uninstaller scripts and packaging hooks to install icons and AppStream metadata reliably.
  • Installer UX: quieter installer output, improved icon handling, and per-user fallbacks so menu entries show icons in common desktops (Cinnamon/GNOME).

Files touched (high level)

  • lsv.cpp — elevation flow (terminal wrapper, pkexec adjustments)
  • install.sh / uninstall.sh — helper install scripts
  • cmake/packaging/postinst — per-user desktop/icon fallbacks
